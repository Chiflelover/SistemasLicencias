===============================================================================
 REQUISITOS DEL SISTEMA — Licencias Municipales, Trujillo
===============================================================================

 IMPORTANTE: este archivo es SOLO DOCUMENTACIÓN.

 "requirements.txt" es el formato de Python (pip). Este proyecto es Node.js, así
 que las dependencias reales viven en package.json y se instalan con:

     npm install

 Correr "pip install -r requirements.txt" no hace nada acá.


-------------------------------------------------------------------------------
 1. QUÉ HACE FALTA TENER INSTALADO
-------------------------------------------------------------------------------

 Node.js        18.17 o superior      (comprobar con: node -v)
 npm            viene con Node        (comprobar con: npm -v)
 Git            cualquier versión     (comprobar con: git --version)

 Base de datos  PostgreSQL. La del proyecto está alojada en Neon
                (https://neon.com), plan gratuito. Sirve cualquier PostgreSQL
                accesible por cadena de conexión.

 Probado sobre Node 24.15.0 y npm 11.12.1, en Windows 10.


-------------------------------------------------------------------------------
 2. CÓMO INSTALARLO
-------------------------------------------------------------------------------

 Hay un instalador que hace todos los pasos y avisa qué variables faltan:

     Windows (PowerShell):
         powershell -ExecutionPolicy Bypass -File scripts\setup.ps1

     macOS, Linux o Git Bash:
         bash scripts/setup.sh

 A mano es lo mismo:

     npm install                # instala las dependencias
     cp .env.example .env       # y completar las variables
     npm run db:setup           # migraciones + cuentas del seed
     npm run dev                # levanta en http://localhost:3000

 NOTA: los scripts no instalan Node ni Git. Si faltan, muestran el comando y se
 detienen, porque eso afecta a toda la computadora y no solo a este proyecto.


-------------------------------------------------------------------------------
 3. VARIABLES DE ENTORNO
-------------------------------------------------------------------------------

 Obligatorias:

     DATABASE_URL           Cadena de conexión a PostgreSQL
     APIPERU_TOKEN          Token de APIPERU. Sin esto no se puede iniciar
                            ningún trámite: valida el RUC contra SUNAT
     JWT_SECRET             Cadena larga y aleatoria para firmar la sesión

 Necesaria en despliegue (Vercel):

     TZ                     America/Lima

 Opcionales (si faltan, esa función no se ejecuta y nada falla):

     GMAIL_USER             Cuenta Gmail que envía los avisos al ciudadano
     GMAIL_APP_PASSWORD     Contraseña de aplicación de esa cuenta
     CALLMEBOT_PHONE        WhatsApp del inspector (con código de país)
     CALLMEBOT_APIKEY       Clave de CallMeBot
     FLOW_PAYMENT_URL       Enlace de cobro de Flow para el pago en línea
     ENABLE_TIME_SIMULATOR  "true" habilita el simulador de fechas
     NEXT_PUBLIC_APP_URL    URL pública de la aplicación

 El detalle de cada una está en .env.example y en el README.

 6. SERVICIOS EXTERNOS
-------------------------------------------------------------------------------

     APIPERU        Consulta de RUC en SUNAT y de DNI en RENIEC.
                    Obligatorio. Las respuestas se guardan en caché 30 días
                    para no gastar cuota.

     Neon           PostgreSQL alojado, plan gratuito.
                    Suspende el cómputo a los 5 minutos de inactividad: la
                    primera consulta después puede fallar. Reintentar.

     Gmail          Envío de correos. Requiere contraseña de aplicación, no la
                    contraseña de la cuenta. Opcional.

     CallMeBot      Aviso por WhatsApp al inspector. Entrega a un único número
                    fijo, el que autorizó el bot. Opcional.

     Flow           Enlace de cobro en línea. No hay integración ni webhook:
                    es un enlace que se abre en otra pestaña. Opcional.

 Todos son gratuitos o tienen plan gratuito suficiente para el proyecto.
